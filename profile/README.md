# Acadia

Open-source embedded Linux platform for **Raspberry Pi (Broadcom)**, from [SoCcentric](https://github.com/Soccentric).
MIT licensed.

| Repository | Purpose |
|---|---|
| [Acadia-OS](https://github.com/soccentric-acadia/Acadia-OS) | Yocto/kas image build |
| [meta-acadia](https://github.com/soccentric-acadia/meta-acadia) | Yocto layer for the board |
| [Acadia-HAL](https://github.com/soccentric-acadia/Acadia-HAL) | Hardware abstraction layer (C++17) |
| [Acadia-Client](https://github.com/soccentric-acadia/Acadia-Client) | gRPC client (C++17) |
| [Acadia-Server](https://github.com/soccentric-acadia/Acadia-Server) | Test server (Drogon, C++) |
| [Acadia-Configuration](https://github.com/soccentric-acadia/Acadia-Configuration) | WebConfig on-device configuration |
| [Acadia-Dashboard](https://github.com/soccentric-acadia/Acadia-Dashboard) | HTML5 dashboard |
| [Acadia-PySDK](https://github.com/soccentric-acadia/Acadia-PySDK) | Python SDK |
| [Acadia-Instrumentation](https://github.com/soccentric-acadia/Acadia-Instrumentation) | On-device management and observability |
| [Acadia-HQ](https://github.com/soccentric-acadia/Acadia-HQ) | Fleet management |
| [Acadia-Hardware](https://github.com/soccentric-acadia/Acadia-Hardware) | Hardware documentation |

Contributions go to the `develop` branch. See the shared [contributing guide](https://github.com/soccentric-acadia/.github/blob/main/CONTRIBUTING.md).
